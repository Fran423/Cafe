This is a project made in Godot for the ysws event Terra by Hack Club.
To run the project, unzip the .zip file and run cafe.exe

controls:
You can grab the filter to put it on either the coffee dispensers (normal coffee or cosmic coffee). This fills it with coffee. Then you can press it with the tamper. You can also grab a cup, glass or to-go cup, put them on the coffee machine along with a tamper that needs to be both filled with coffee and pressed to fill it. You can add ice into the cup by dragging it from the black box to whichever cup you prefer. Once finished, you can bring the cup to the costumer on the right. Clicking the costumer will make it grade the cup from 0% to 100%, depending on how accurate it is to their description (which appears above the button)

This project attempts to be a cafe simulator for windows and android, including various new aspects i had never worked on. The powerful drag-and-drop system being the main one.
