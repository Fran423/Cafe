This is a project made for the ysws event Terra by Hack Club.
To run the project, unzip the .zip file and run cafe.exe
you can grab the item on the up left of the coffee machine to put it on the white rectangle. This fills it with coffee. Then you can press it with the item to the lower right. You can also grab the item on the lower left to move it around and let it fall on the right side.
This project attempts to be a cafe simulator, including various new aspects i had never worked on
